# Curtain Up

노래하기 전 가볍게 목풀기(발성 연습) 웹앱입니다. 지인 베타 테스트용으로 공개합니다.

**바로 사용하기:** https://junechae99-stack.github.io/curtain-up/

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `스케일파일/index.html` | 앱 본체 (스케일 연습, 루틴, 내 패턴 만들기, 음정 피드백) |
| `index.html` | 짧은 주소로 들어오면 앱으로 넘겨 주는 페이지 |

내 패턴과 설정은 각자의 브라우저에만 저장되고, 마이크 소리는 기기 안에서만 분석합니다.
